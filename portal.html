Uncheck this on a shared or school computer.

How do I get a GitHub key?
  1. Open github.com/settings/tokens/new and sign in.
  2. Note: type a name you haven't used before, like Classroom portal 3.
  3. Expiration: No expiration, or the end of the school year.
  4. Check the box repo.
  5. Click Generate token, copy the key (starts with ghp_) and paste it above.

Keep this key private, like a password. Save it in a password manager so you don't lose it.
