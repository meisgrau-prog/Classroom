Set Up Password

Do this once. It locks your GitHub key with a password, so after this you (or anyone you give the password to) can sign in with just the password.

How do I get a GitHub key?
  1. Open github.com/settings/personal-access-tokens/new.
  2. Token name: Classroom portal (or any name you haven't used).
  3. Expiration: the longest option, or the end of the school year.
  4. Repository access: Only select repositories → Classroom.
  5. Permissions: click Add permissions → Contents, then set Contents to Read and write.
  6. Click Generate token and copy it.

This kind of key can only change your Classroom website — nothing else on your GitHub account — which keeps things safer if the password is ever shared.

At least 10 characters. A short phrase works well, like blue-apple-river-42.
