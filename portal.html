Set Up Password

Do this once. It locks your GitHub key with a password, so after this anyone you give the password to can sign in with just the password.

How do I get a GitHub key?
  1. Open github.com/settings/tokens/new.
  2. Note: a name you haven't used, like Classroom portal 4.
  3. Expiration: No expiration, or the end of the school year.
  4. Check the box repo, click Generate token, and copy it.

At least 10 characters. A short phrase works well, like blue-apple-river-42.

Who can open the Parent Portal?

Class Password

The one password families type to open the Parent Portal. With parent profiles, it's also the class code for making a profile.

This is a privacy screen for families and students. Because the website is stored on public GitHub, a technical person could still find posted files there, so don't post anything truly confidential. Use a different password from the Teacher Portal password.

Parent Profiles

Each parent signs in with their own email and password, and can reset a forgotten password by email.

See & remove parents in Firebase ↗

How to set up parent profiles (one time, about 10 minutes)
  1. Go to console.firebase.google.com and sign in with a Google account. Click Create a project, name it (e.g. Rabbi Eisgrau Class), turn Google Analytics off, and finish. The free plan is all you need.
  2. Left menu: Security → Authentication → Get started (if you don't see it, click All products or search “Authentication” at the top). On the Sign-in method tab choose Email/Password, switch the first toggle on, and Save.
  3. Click the gear ⚙ → Project settings. Copy the Project ID.
  4. Under Your apps, click </> (Web), name it Class website (leave Firebase Hosting unchecked), and Register app. Copy only the apiKey value — it starts with AIza.
  5. Paste both above, click Test connection (it should say “✓ Connected”), set a Class password for the class code, and click Save & Publish.
  6. Optional: Security → Authentication → Templates → Password reset → change the sender name to your name so families recognize the email.

Give families the Parent Portal address and the class code. To remove a parent, open the Parents tab, where you can see, edit, block or delete parent profiles.

All changes saved.
