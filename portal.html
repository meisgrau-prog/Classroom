How do I get my GitHub key? (one time only)
  1. Sign in to GitHub, then open github.com/settings/personal-access-tokens/new.
  2. Token name: type Classroom portal.
  3. Expiration: choose the longest option (or a custom date at the end of the school year).
  4. Repository access: choose Only select repositories, then pick Classroom.
  5. Permissions → Repository permissions → Contents: change to Read and write.
  6. Click Generate token, copy the key that starts with github_pat_, and paste it above.

Keep this key private, like a password. Don't email it or share it with anyone.
